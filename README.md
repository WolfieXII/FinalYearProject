# Final Year Project
In this repo you'll find the Assets used to create the project.
The Assets folder contains the files for the scene that was created in Unity for the Agent to navigate within. This folder also contains the source code files for the agent configurations, these files are:

- RollerAgent.cs - Is the file used for scene manipulation and Agent Configuration.
- Rollerball_config.yaml - Contains the parameters for the agent when training occurs.
- KeyData.cs - Contains the type of keys the agent will be able to collect (Red, Green, Blue).
- DoorData.cs - Contains the type of doors the agent will be able to interact with (Red, Green, Blue).

Due to the size of the Unity Project, not all files are able to be uploaded. However, all the code relating to the agent and scene have been uploaded which can be viewed above.
